Phân tích & Lựa chọn giải phápĐề xuất 2 giải pháp tái cấu trúc:Giải pháp 1 (Flat Struct Optimization): Cấu trúc phẳng, sắp xếp các biến theo thứ tự kích thước giảm dần (vd: double $\rightarrow$ int $\rightarrow$ char).Giải pháp 2 (Nested Struct): Nhóm các biến theo chức năng (Điện, Trạng thái) thành các struct lồng nhau.Lựa chọn: Chọn Giải pháp 1.Lý do: Đối với vi điều khiển IoT Gateway, tiết kiệm RAM là ưu tiên số 1. Sắp xếp biến lớn lên đầu triệt tiêu tối đa Memory Padding (giảm kích thước struct từ 48 bytes xuống 32 bytes), đồng thời truy xuất dữ liệu O(1) cực nhanh, không qua nhiều lớp.Luồng xử lý: Khai báo struct $\rightarrow$ Nhập liệu $\rightarrow$ Validate ranh giới dữ liệu $\rightarrow$ So sánh sai lệch công suất (5%) $\rightarrow$ Cảnh báo quá tải/rò rỉ $\rightarrow$ Tính kWh.
